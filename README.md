# Backend → AI Engineer — 6 Month Roadmap

## 🎯 Goal

Become a job-ready AI Engineer by combining existing Backend Engineering experience with:

- Machine Learning
- Deep Learning
- LLM Engineering
- AI Agents
- Production AI
- AI System Design

Starting point:

Backend Engineering + RAG Experience

Target:

AI Engineer / Applied AI Engineer

- Statistics

### Email Spam Detection API
