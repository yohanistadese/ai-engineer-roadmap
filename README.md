# Backend to AI Engineer 🚀

> A 12-month roadmap to become a production-ready AI Engineer by combining Backend Engineering, Machine Learning, LLMs, AI Infrastructure, and Distributed Systems.

## 🎯 Goal

My goal is to transition from **Backend Engineer → AI Engineer / Applied AI Engineer** within 12 months and become competitive for strong international remote AI Engineering roles.

I am not trying to become only a prompt engineer or only an LLM API developer.

The goal is to become an engineer who can:

- Design AI systems
- Build AI-powered backend systems
- Understand ML and Deep Learning fundamentals
- Build LLM applications
- Build RAG systems
- Build agentic systems
- Evaluate AI systems
- Deploy AI systems
- Scale AI workloads
- Understand AI infrastructure
- Design distributed systems
- Build production-ready AI products
